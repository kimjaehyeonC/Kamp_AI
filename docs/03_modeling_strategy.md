# 03 — 모델 학습·평가 전략

## 기본 단위와 데이터 분할

- 원시 시계열을 먼저 세그먼트로 나누고, **세그먼트 1개를 하나의 cycle 표본**으로 사용한다.
- 인접 세그먼트는 서로 유사하므로 무작위 분할하지 않고 **시간순 연속 블록**으로 나눈다.
- 정상 데이터는 앞 60%를 train, 다음 20%를 validation, 마지막 20%를 test로 사용한다.
  - train: 피처 기준·스케일러·모델 학습
  - validation: threshold와 `N개 중 M개` 경보 규칙 설정
  - test: 정상 오경보율 최종 평가
- 현재 outlier는 별도 시점의 단일 이상 에피소드다. 세그먼트를 무작위 분할하기보다 시간순
  그대로 투입해 cycle 단위 이상 탐지율과 미탐률을 평가한다.

현재 유효 피처는 outlier를 참고해 선택했으므로 해당 outlier 성능은 완전한 외부 검증이 아니라
**공모전 개발 데이터 내 성능**으로 해석한다. 이 한계는 감안하되, 확보된 이상 징후를 최대한
활용해 모델을 비교한다.

## 모델링 우선순위

1. `normal_center_nrmse` 단일 threshold를 기준선으로 둔다.
2. `band_purity`, 진동 RMS·자기상관, `env_cv`, `ai1_peak_hz`, `cur_vib_resid` 등을 결합한
   one-class 모델(Mahalanobis, Isolation Forest, One-Class SVM)을 비교한다.
3. 공모전용 비교군으로 정상·이상 피처를 함께 쓰는 Logistic Regression, SVM 등 단순
   지도학습 모델도 평가한다. 이상 표본이 적으므로 복잡한 모델의 과적합에 주의한다.
4. cycle 이상 점수에 **최근 N개 중 M개 초과** 규칙을 적용해 일시적 오경보를 줄인다.
5. 딥러닝은 주력이 아니라 비교 실험으로 둔다. 시도한다면 padding/mask를 적용한 원시 파형
   1D-CNN autoencoder를 PCA 재구성 오차 및 피처 기반 ML과 비교한다.

## 공통 평가 지표

이상을 양성으로 정의하고, 모든 모델을 동일한 평가 표본과 기준으로 비교한다.
정상 test와 학습에 사용하지 않은 outlier에서 아래 다섯 지표를 보고한다.

| 지표 | 계산 | 평가 데이터 |
|---|---|---|
| 정상 탐지율(정상 판정률) | TN / (TN + FP) | 정상 test |
| 이상 탐지율 | TP / (TP + FN) | outlier |
| 오경보율 | FP / (TN + FP) | 정상 test |
| 미탐률 | FN / (TP + FN) | outlier |
| Balanced Accuracy | (정상 탐지율 + 이상 탐지율) / 2 | 두 평가 데이터 종합 |

비율과 함께 판정 건수·분모를 표시한다. 정상 탐지율과 오경보율, 이상 탐지율과 미탐률은
각각 합이 100%다. 모델 선정은 **허용 오경보율을 만족하는 모델 중 이상 탐지율**을 우선하고,
Balanced Accuracy로 종합 성능을 비교한다. 단일 NRMSE 기준선 대비 개선 여부도 확인한다.
F1, AUC, 시간당 오경보 수, 에피소드 탐지 여부·최초 경보 지연 등 추가 지표는 추후 검토한다.

## 평가 보강 사항

- 60/20/20 단일 분할 외에 블록 k-fold 또는 부트스트랩으로 오경보율에 신뢰구간을 붙인다.
  표본이 작아 점추정만으로는 모델 간 차이를 판단하기 어렵다.
- 전환구간(00:55~01:17, 진입/저점/복귀) 점수를 시간축에 그대로 플롯해 경계에서 점수가
  급변하는지 진단한다. fold 분할과 별개로, train/test 구분 없이 확인한다.
- 세그먼트 단위 회귀테스트를 둔다: seg3·19·20(미탐 후보), n≈23 부근(오탐 후보)을 모델마다
  개별 확인한다. 집계지표에 묻히지 않도록 한다.
- 세그먼트 길이 구간별로도 분해해서 평가한다. rms 계열은 n=10~19에서 분리력이 크게
  떨어진 전례가 있다. 새 모델이 같은 구간에서도 같은 문제를 겪는지 확인한다.
