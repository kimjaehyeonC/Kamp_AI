# 3. 영향요인 및 오류분석

## 3.1 주요 영향변수

세 가지 서로 다른 방법(Mahalanobis의 정확한 D² 기여도 분해, Isolation Forest의
permutation importance, One-Class SVM의 permutation importance + KernelSHAP)이
**동일한 결론으로 수렴**한다(`05_oneclass.ipynb` ## 7, 7-1).

| 피처 | 역할 |
|---|---|
| `normal_center_nrmse` | **압도적 1위.** 전류 파형이 정상 사인 패턴에서 벗어난 정도. 모든 이상 세그먼트에서 D² 기여가 최소 수백~최대 10만 단위로 다른 피처를 압도한다. |
| `cur_ai1_resid` | 보조 피처. 특정 서브유형(아래 3.2절)에서만 2위로 올라와 결정적 역할을 한다. |
| `cur_ai0_resid` | 보조 피처. 대부분의 이상 세그먼트에서 2~3위 기여. |

[그림 3-1 필요] 세 가지 설명법(D² 분해 / IF permutation / SVM permutation+SHAP)의
피처 중요도를 나란히 놓은 막대그래프 3연. 현재는 표로만 존재(`05_oneclass.ipynb` ##
7, 7-1) — 세 방법의 수렴을 시각적으로 보이려면 신규 그래프 추가 권장.

## 3.2 변수 간 상호작용 — 실패 유형의 분기

상부(`AI0`)-하부(`AI1`) 진동의 순간상관(`inst_corr`)을 보면 이상 세그먼트가 두 유형으로
갈린다(`02_eda_segment_features.ipynb` 5절):

- **"시끄러움" 유형(12개)**: 진동이 전류 대비 과도하게 큼. 상하부가 역상관(평균
  `inst_corr≈-0.42`)을 보인다. `normal_center_nrmse`와 `cur_ai0_resid`가 거의 동률로
  공동 1위.
- **"조용함" 유형(seg19·20 등)**: 전류·상부진동 각각은 정상 범위인데, **전류 대비
  하부진동 잔차(`cur_ai1_resid`)만 음수로 이상**. 이 유형에서만 `cur_ai1_resid`가
  2위로 올라온다 — 이 피처가 설계 의도(전류-진동 결합이 끊어지는 조용한 고장)대로
  정확히 작동한다는 증거다.

즉 `normal_center_nrmse` 하나로는 "시끄러운" 고장과 "조용한" 고장을 구분할 수 없고,
`cur_ai1_resid`와의 **상호작용**(어느 쪽이 함께 뛰는지)이 실패 유형을 가른다.

## 3.3 오경보(FP)가 집중되는 공정조건

`05_oneclass_fp_analysis.ipynb`에서 정상 전체(530개, n≥10)를 전부 다시 스캔한 결과:

- **held-out(학습에 쓰지 않은 validation+test, 217개) 기준 Mahalanobis·Isolation
  Forest 오경보 = 0건.** One-Class SVM만 1건(seg437).
- 그 1건은 **전환구간(V-dip) 진입 시점(00:55:11)의 짧은 사이클(n=10)**에서 발생했다
  — 불안정한 시간대와 짧은 사이클이 겹쳤을 때 상대적으로 덜 안정적인 모델이 흔들린다는
  구체적 조건이다.
- 세 모델 전부에서 연속 오경보(같은 세그먼트가 여러 번 이어 걸리는 경우)가 **단 한
  건도 없었다** — "일시적 운전변화로 몇 사이클 연속 오탐"이라는 실패 모드 자체가 이
  데이터에는 없다는 뜻이다. (이 결과가 4장의 "지속성 규칙 불필요" 판단의 근거다.)

[그림 3-2 존재함] 전환구간(V-dip) 시간축 진단 플롯 — 정상 전체 구간의 모델별 점수를
시간순으로 찍고 V-dip 구간을 음영 표시한 그래프. `05_oneclass_fp_analysis.ipynb`
## 7(코드 셀, `plt.subplots(3,1,...)`)에 이미 작성돼 있다. 보고서에는 이 그림을
그대로 인용.

**가장 결정적인 FP 조건은 세그먼트 길이다.** n<10(정상의 11.5%)을 포함해 다시 평가하면
Mahalanobis조차 오경보율이 **32.2%**로 치솟는다(One-Class SVM 42.4%, Isolation
Forest만 6.8%로 상대적으로 안정). 이는 `normal_center_nrmse`가 사인파 2개 계수를
추정하는데 필요한 자유도 대비 샘플이 부족해 통계적으로 불안정해지기 때문이며, **04의
정적 규칙도 동일하게 무너진다**(오경보율 18.6~40.7%, `04_rule_base.ipynb` ## 6) — 즉
모델 선택의 문제가 아니라 피처 자체가 짧은 사이클에서 통계적으로 불안정해지는 근본
문제임을 교차 확인했다(2.4절의 2-track 대응으로 연결).

[그림 3-3 존재함] 세그먼트 길이 구간별(2~9 / 10~19 / 20~29 / ≥30) 모델별 오경보율·
탐지율 막대그래프. `05_oneclass_fp_analysis.ipynb` ## 9-1(코드 셀)에 이미 작성돼
있다.

## 3.4 미탐(FN)이 집중되는 공정조건

Mahalanobis·One-Class SVM은 n≥10에서 6-fold 전체 미탐 0건이다. Isolation Forest만
단일 분할 기준 4건(seg3·15·19·20)처럼 보였으나, **6개 폴드 각각 독립 학습한 모델로
재검증하면 구조적으로 항상 놓치는 건 seg3 하나뿐**이었다(나머지 3개는 그 특정 분할의
train 샘플에서만 생긴 우연, `05_oneclass_fp_analysis.ipynb` ## 9).

seg3의 조건을 분석하면: 3개 피처 중 `normal_center_nrmse` 하나에서만 이상치고(z≈80),
`cur_ai0_resid`·`cur_ai1_resid`는 둘 다 정상 범위(|z|<2)다. 게다가 그 하나의 피처에서도
다른 이상 세그먼트(z 110~290)보다 덜 극단적이다. **즉 미탐이 집중되는 조건은 "여러
피처가 아니라 단 하나의 피처에서만, 그것도 상대적으로 약하게 벗어나는 경우"다.**
Isolation Forest의 무작위 분할 방식은 이런 경우를 고립시키는 데 약하고, 공분산을
명시적으로 쓰는 Mahalanobis는 이 경우에도 놓치지 않았다(설계상 D²가 모든 방향의
편차를 자동으로 합산하기 때문).

[그림 3-4 존재함] 피처 평면(전류잔차 2개 평면, NRMSE×하부전류잔차 평면) 산점도에
seg3(진짜 미탐)와 FP 세그먼트를 강조 표시한 그래프.
`05_oneclass_fp_analysis.ipynb` ## 10(코드 셀)에 이미 작성돼 있다.

## 3.5 종합

| 오류 유형 | 집중 조건 |
|---|---|
| 오경보(FP) | ① 세그먼트 길이 n<10(가장 결정적, 오경보율 최대 42%) ② 전환구간(V-dip) 인접 × 짧은 사이클 × 상대적으로 덜 안정적인 모델(One-Class SVM) |
| 미탐(FN) | 단일 피처에서만, 상대적으로 약하게 벗어나는 경우(seg3) — Isolation Forest 계열 모델에서만 발생, Mahalanobis는 발생 안 함 |

채택 모델(Mahalanobis, n≥10 구간)은 530개 정상·17개 이상 전체와 6-fold 교차검증
전부에서 FP 0, FN 0이었다 — 오류가 "집중"되는 조건 자체가 관찰되지 않았다. 유일하게
확인된 취약점은 비교 모델(One-Class SVM, Isolation Forest)에서만 나타났고, 그 조건이
위와 같이 구체적으로 특정됐다.
