# 02 — 피처 후보 정리 (현재 상태)

`notebooks/02_eda_segment_features.ipynb`(이하 02-2) 결과를 기반으로 한 피처 후보 종합.
`01_eda_findings.md`의 상세 서술(섹션 5~14)을 보완하는 **요약·추적용 문서**이며, 내용이
바뀔 때마다 이 문서를 갱신한다. 세그먼트/오경보·미탐 등 기본 용어는 `01_eda_findings.md` 참고.

## 상하부 진동(AI0 vs AI1) 관계 — 02-2 섹션 5 요약

- **주파수**: normal에서 AI0 ~3.3~3.5Hz, AI1 ~1.8~1.9Hz로 하부가 뚜렷이 느리다(n≥15부터
  안정, 길이 아티팩트 아님). **단, 진폭까지 작은 건 아니다** — rms 비율(AI1/AI0) 중앙값 1.38로
  하부가 오히려 더 크다. "느리지만 크게" 흔든다.
- **상하 대칭(역상관)**: outlier에서 corr<-0.5가 23.8%(normal 0.8%). 다만 **보편적이지 않다** —
  "진동이 전류 대비 과도하게 큰" 실패 유형(12개, inst_corr 평균 -0.42)에서만 나타나고,
  "전류 대비 진동이 조용한" 유형(seg16·17·18·19·20, inst_corr 평균 +0.07)에는 없다.
  → 두 실패 유형이 상하부 관계 패턴에서도 갈린다.
- **전류-진동 결합**: `AI1_rms ↔ 전류_rms` 상관이 normal 0.90~0.97(길이 전 구간 안정,
  Pearson≈Spearman로 선형)인데 outlier에서 거의 0(-0.06~-0.14)으로 붕괴. 이 선형관계의
  **잔차**(`cur_vib_resid` = 실제 AI1_rms − 전류로 예측한 AI1_rms)가 **음수**인 세그먼트가
  바로 위 "조용한" 실패 유형과 일치 — seg16·17·18·19·20을 전부 잡는다.
- **실패한 시도**: 두 채널 "주파수 차이"(AI0 peak_hz − AI1 peak_hz)를 세그먼트별로 직접
  빼면 AUC 0.53(무의미) — 집계 중앙값은 갈려도 세그먼트 단위 차이는 상쇄된다. **차이가
  아니라 절대 주파수 값**(`ai1_peak_hz` 단독 AUC 0.952)을 피처로 써야 한다.

## 정상 중심 고정 사인 잔차 — 현재까지 최고 피처 (02-2 섹션 3~4, 오늘 추가 검증)

`AI2_Current`를 정상 공통 주기(0.6Hz/1.667s)로 고정하고, 정상 train 기준 중심값(0.549)
또는 진폭까지 고정해 사인을 적합한 뒤 NRMSE를 본다.

```
normal test(n≥10) NRMSE: [0.019, 0.104]   (165개)
outlier    (n≥10) NRMSE: [0.888, 5.199]   (17개)
겹침 없음 → AUC = 1.0000
```

**seg3·19·20(01/02/03 전부에서 반복된 미탐지)을 전부 큰 여유로 잡는다** —
seg19(n=10) NRMSE 2.00(정상 최댓값의 19배), seg20(n=15) 5.20(50배), seg3(n=31) 1.47(14배).
`band_purity`(AUC 0.995)보다 좋고, `cur_vib_resid`로 메꿨던 구멍까지 단독으로 덮는다.

**남은 한계는 n<10으로 좁혀진다**(seg0·5·9·10, 4개뿐). n=3인 seg5는 NRMSE 0.096으로
정상과 구분 안 됨 — 너무 짧으면 자유도 대비 관측치가 부족해 여전히 과적합된다.
**별도 처리(병합/제외 등)는 차후 다룬다 — 지금은 보류.**

## 피처 후보 종합표

### A. 검증 완료 / 강력 추천

| 피처 | AUC | 조건·한계 |
|---|---:|---|
| **정상중심 고정 사인 잔차(NRMSE)** | **1.000 (n≥10)** | 최고 성능. n<10만 미해결 |
| `band_purity`(전류 사인 순수도) | 0.995 | n≈23 부근 불안정(03의 유일한 오탐 원인) |
| `env_cv`(진동 균일성) | 0.978 (n≥20) | n<20 결측, n≥10까지 낮추면 0.89로 하락 |
| `ai0_ac1` | 0.962 | AUC 높지만 FP=0 운영점에서 최악(8/17) — AUC만으로 판단 금지 |
| `ai0_rms` | 0.849 (n≥10) | 기준 피처, n=10~19에서 AUC 0.52로 붕괴(아래 참고) |

### D. 확인 필요 (다음 단계)

1. **길이 구간별 AUC 붕괴가 보편적 현상**: `ai0_rms`/`ai1_rms` 모두 n=10~19에서 AUC
   0.52~0.54(거의 무작위), n≥20에서 급등. 미탐지 seg19(n=10)·20(n=15)이 정확히 이 구간 —
   rms 계열 피처는 이 길이대에서 원천적으로 무력화된다는 뜻. **normal중심 NRMSE는 이
   문제가 없어 보이므로(n≥10 AUC 1.0), 길이 문제의 상당 부분을 이걸로 우회할 수 있을지
   확인 필요.**
2. A+B 전체를 03의 OR 규칙에 합쳤을 때 종합 탐지율·오경보율 — 개별로만 확인했고 전체
   조합 평가는 안 함.
3. B 피처들 간 상호 중복성(`inst_corr` vs `ratio_ai1_ai0` vs `ai1_peak_hz`).
4. 03의 정상 내부 오경보율(70/30 분할) 재측정 — 현재 버전은 B 피처 반영 전.
5. n<10 세그먼트(4개) 별도 처리 — **차후 진행, 지금은 보류**.
6. 근본 한계: 모든 결과가 동일한 77분 normal + 2.8분 outlier 안에서 나왔다
   (`01_eda_findings.md` 섹션 3 교락 문제). 다른 날짜 데이터 없이는 일반화 불가.
